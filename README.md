## 📌 About The Project

**HCA Healthcare Analytics Dashboard** is an interactive **Business Intelligence and Data Analytics project** developed using Microsoft Power BI.

The dashboard transforms healthcare data into meaningful insights related to:

- 👥 Patient Analytics
- 🏥 Hospital Performance
- 👨‍⚕️ Doctor Performance
- 💰 Revenue Analysis
- 🛡️ Insurance Coverage
- ⭐ Patient Satisfaction
- 🩺 Disease Analysis
- 📅 Monthly Revenue Trends
- 💊 Treatment Outcomes

The goal of this project is to demonstrate how **Power BI, DAX, Data Modeling, and Data Visualization** can be used to convert raw healthcare data into actionable business insights.
